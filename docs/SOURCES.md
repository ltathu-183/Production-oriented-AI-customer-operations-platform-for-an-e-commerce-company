# Nguồn chính để tham khảo / trích dẫn

1. Oxford-IIIT Pet dataset — University of Oxford Visual Geometry Group
   https://www.robots.ox.ac.uk/~vgg/data/pets/

2. Torchvision OxfordIIITPet dataset API
   https://docs.pytorch.org/vision/stable/generated/torchvision.datasets.OxfordIIITPet.html

3. Torchvision DeepLabV3 + MobileNetV3-Large API
   https://docs.pytorch.org/vision/main/models/generated/torchvision.models.segmentation.deeplabv3_mobilenet_v3_large.html

4. U-Net paper
   Ronneberger, Fischer, Brox. U-Net: Convolutional Networks for Biomedical Image Segmentation (2015).
   https://arxiv.org/abs/1505.04597

5. DeepLabV3 paper
   Chen et al. Rethinking Atrous Convolution for Semantic Image Segmentation.
   https://arxiv.org/abs/1706.05587
